# Java Basics Exercises

The purpose of these exercises is to familiarize yourself with the basics of Java and how to submit and evaluate your solutions in the Viope platform.

For each exercise, create an exercise-specific `.java` file in the `week1` folder. For example, code for the first exercise should be written in the `Exercise1.java` file.

```
src/
└── main/
    └── java/
        └── week1/
            ├── ...
            └── Exercise1.java 👈
```

> [!IMPORTANT]
> In each exercise, write the code in VS Code. When you have confirmed the code is working as the exercise requires, submit your solution to the Viope the platform for evaluation. The first exercise goes through the instructions.

### Exercise evaluation in Viope

Once your code works in VS Code, copy-paste your solution to Viope for evaluation. **Exercise evaluation must pass in Viope in order the exercise to be considered completed**. Follow the [Getting started with the Viope platform](#) instructions to learn how to submit your exercise.

In Viope, remember to remove the first, `package week1;` line from your `.java` file.

```diff
- package week1;

public class Exercise1 {
    public static void main(String[] args) {
        // ...
    }
} 
```
