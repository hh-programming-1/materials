# Strings & Dates Warm-up Exercises

For this week's exercises, create a new `week4` package (folder) under the `src/main/java` folder. For each exercise, create an exercise-specific `.java` file in the `week4` folder.

```
src/
└── main/
    └── java/
        ├── ...
        └── week4/ 👈
            └── WarmUp1.java 👈
```

> [!IMPORTANT]
> **Warm-up exercises are not submitted or evaluated in Viope**. The purpose of these exercises is to practice the topics with the help of the model solutions.

## Warm-up exercise 1

Create an application that asks the user for a sentence and prints how many words it contains. First, make a version where words are separated by spaces. Then modify it so that punctuation (commas, periods, question marks, and exclamation marks) is also taken into account. How many different solutions can you come up with?

## Warm-up exercise 2

Create an application that asks the user for a string and tells them whether it is a palindrome. A palindrome is text that reads the same in both directions, for example "madam". First, make a version that works with individual words. Once it works, modify the code so that punctuation (commas, spaces, etc.) is ignored and letter case does not matter. For example, "ma d AM" is a palindrome.

## Warm-up exercise 3

Create an application that asks the user for a PIN (4–8 characters). First, check that the entered PIN contains only digits. Next, ask the user to enter the PIN again and check that the two entries match. If they do not match, ask again. If the user enters an incorrect PIN three times, the application should report "PIN invalid"; otherwise, it should report "PIN valid".

## Warm-up exercise 4

Create an application that tells the user when Midsummer Eve falls in the current year. Rule: Midsummer Day is the Saturday between June 20 and June 26.

## Warm-up exercise 5

Create an application that tells the user when Friday the 13th will occur next.
