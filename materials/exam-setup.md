# Exam setup

> [!CAUTION]
> The following things are forbidden during the exam:
>
> - Using any kind of generative AI tools to generate code or prompt for help (including VS Code's tools, e.g. Copilot).
> - Using any external sources. Only the exam materials and VS Code window should be open during the exam.
>
> Violating these will lead to a failing grade from the course.

1. [Download the exam template Java project](https://github.com/hh-programming-1/programming-1-exam/archive/refs/heads/main.zip) (compressed ZIP folder) for the exam exercises. Extract the ZIP folder on your computer. Move the extracted folder to a convenient location
2. Open VS Code and choose "File" > "Open Folder". Choose the template Java project folder to open it.
3. All the relevant content of the template project is in the `src/main/java` folder. In that folder, there's a `exam` folder, in which all the exerice-related `.java` files should be added (further instructions in the exam).

```
src/
└── main/
    └── java/
        └── exam/ 👈
```
